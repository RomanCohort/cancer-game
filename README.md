# 抗癌文字冒险游戏

## 游戏简介

《抗癌文字冒险游戏》是一款基于Python的文字冒险游戏，玩家扮演人体免疫系统，指挥各种免疫细胞对抗癌细胞。游戏结合策略、战斗和探索元素，通过游戏化方式普及生物医学知识，同时提供紧张刺激的玩法体验。

## 游戏特色

- **教育性强**：融入真实免疫系统知识，了解T细胞、B细胞等功能
- **多样免疫细胞**：T细胞、B细胞、巨噬细胞、自然杀伤细胞等，各具特色
- **动态战斗**：回合制战斗，支持技能、物品、敌人逃窜和增援
- **探索机制**：在人体器官中探索，解锁隐藏内容
- **任务系统**：完成任务获得奖励和升级
- **年龄影响**：不同年龄阶段影响初始细胞数量和难度
- **无尽模式**：无限挑战，难度递增
- **保存加载**：支持进度保存

## 系统要求

- Python 3.6+
- 无外部依赖

## 安装和运行

1. 安装Python 3.6+
2. 下载 `文字冒险游戏.py`
3. 运行：`python 文字冒险游戏.py`

## 游戏玩法

### 开始
选择年龄阶段（20岁/40岁/80岁/晚期），获得初始免疫细胞。年龄影响初始细胞数量和游戏难度。

### 核心玩法
- **前进**：移动到新房间，探索人体器官
- **战斗**：与癌细胞战斗，使用免疫细胞对抗
- **探索**：发现隐藏物品和秘密
- **任务**：完成目标获奖励和升级
- **管理**：使用ATP治疗，管理资源和精神健康

### 细胞类型
- **T细胞**：攻击癌细胞，擅长直接战斗
- **B细胞**：产生抗体，支持补体系统
- **巨噬细胞**：吞噬敌人，提供增援
- **自然杀伤细胞**：快速消灭弱敌
- **补体系统**：激活后增强攻击

### 命令列表
- **前进**：移动到下一区域
- **战斗**：进入战斗模式
- **状态**：查看当前状态和资源
- **物品**：管理背包物品
- **技能**：使用特殊技能
- **治疗**：消耗ATP恢复细胞
- **休息**：恢复精神健康
- **探索**：搜索当前区域
- **任务**：查看和完成任务
- **商店**：购买物品和升级
- **edu**：显示免疫系统和抗癌知识
- **保存**：保存游戏进度
- **加载**：加载已保存进度
- **帮助**：显示帮助信息
- **退出**：退出游戏

### 自测模式
运行 `python 文字冒险游戏.py selftest` 进入自测模式，自动测试游戏机制如逃跑、随机事件和物品副作用。

### 教育命令
- **edu**：提供详细的生物医学知识，包括免疫细胞、癌症、药物、疗法、技能和事件。帮助玩家在游戏中学习科学知识。

## 战斗系统
回合制，选择目标和行动。敌人可能逃窜，后续再遇。

## 资源管理
- ATP：能量，用于治疗
- 供应等级：影响恢复
- 精神健康：影响表现

## 提示
- 合理搭配细胞类型，针对不同敌人选择合适策略
- 及时治疗和探索以维持优势
- 完成任务获额外奖励
- 经常保存进度，避免丢失
- 使用edu命令学习知识，提升游戏体验

## 常见问题
- **如何开始游戏？** 运行 `python 文字冒险游戏.py`，选择年龄阶段。
- **战斗中敌人逃跑怎么办？** 逃跑的敌人会在后续战斗中出现，需及时清除。
- **ATP不够怎么办？** 通过战斗胜利或完成任务获得ATP。
- **游戏崩溃怎么办？** 检查Python版本，确保为3.6+。如有错误，可运行自测模式检查。
- **如何学习科学知识？** 使用edu命令，查看详细的免疫和抗癌知识。

# 文字冒险游戏 - 打包说明

## 打包为本地软件

这个游戏可以打包成Windows可执行文件（.exe），无需安装Python即可运行。

## 方法一：使用打包脚本（推荐）

1. **安装依赖**（如果还没安装）：
   ```
   pip install -r requirements.txt
   ```
   或者直接：
   ```
   pip install pyinstaller
   ```

2. **运行打包脚本**：
   - 双击运行 `build_exe.bat`（Windows）
   - 或者运行 `python build_exe.py`

3. **获取可执行文件**：
   - 打包完成后，可执行文件位于 `dist` 文件夹中
   - 文件名为 `文字冒险游戏.exe`
   - 可以直接运行，无需Python环境

## 方法二：手动打包

如果你熟悉命令行，也可以手动执行：

```bash
pyinstaller --onefile --console --name=文字冒险游戏 "文字冒险游戏.py"
```

## 打包选项说明

- `--onefile`: 打包成单个exe文件（推荐，方便分发）
- `--console`: 显示控制台窗口（此游戏为命令行游戏，需要控制台）
- `--name=文字冒险游戏`: 指定输出文件名

## 分发

打包完成后，你可以：

1. 将 `dist/文字冒险游戏.exe` 复制到任何Windows电脑
2. 直接双击运行，无需安装Python或其他依赖
3. 可以将exe文件和说明文档一起打包分享

## 注意事项

- 打包后的exe文件较大（通常50-100MB），这是正常的（包含了Python解释器和所有依赖）
- 首次运行可能需要几秒钟启动时间
- 如果杀毒软件报警，这是误报（PyInstaller打包的程序有时会被误报），可以添加到白名单
- 存档文件（.pkl）和exe文件需要在同一目录，或者使用完整路径

## 游戏说明

这是一个以抗癌为主题的文字冒险游戏，玩家扮演免疫系统中的辅助T细胞，通过战斗、探索、管理资源来对抗癌细胞。

### 基本命令：
- `前进`: 前往下一个区域
- `战斗`: 与敌人战斗
- `状态`: 查看当前状态
- `物品`: 使用物品
- `技能`: 使用技能
- `治疗`: 进入治疗菜单
- `休息`: 恢复补给
- `探索`: 探索当前区域
- `任务`: 查看任务
- `商店`: 进入商店
- `保存`: 保存游戏
- `加载`: 加载游戏
- `帮助`: 查看帮助
- `退出`: 退出游戏
